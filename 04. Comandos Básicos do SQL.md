O SQL (Structured Query Language) é a linguagem padrão utilizada para interagir com bancos de dados relacionais. Ele permite definir a estrutura dos dados, manipular os registros e controlar o acesso às informações. Nesta introdução, exploraremos os principais comandos do SQL, divididos em categorias, e exemplos práticos para facilitar o entendimento.

# 1. DQL (Data Query Language) – Consulta de Dados

A DQL é usada para recuperar informações armazenadas no banco de dados, sendo o comando principal o **SELECT**.

## SELECT

O comando **SELECT** permite escolher colunas específicas ou todos os campos de uma tabela.

**Sintaxe básica:**
```sql
SELECT coluna1, coluna2 FROM tabela;
```

**Exemplo:**
```sql
SELECT nome, idade FROM alunos;
```
Este comando retorna as colunas `nome` e `idade` da tabela `alunos`.

## Comandos Auxiliares em SELECT

- **WHERE:** Filtra os registros com base em uma condição.
  ```sql
  SELECT * FROM alunos WHERE idade >= 18;
  ```
- **ORDER BY:** Ordena os resultados de acordo com uma ou mais colunas.
  ```sql
  SELECT * FROM alunos ORDER BY nome ASC;
  ```
- **LIMIT:** Restringe o número de registros retornados.
  ```sql
  SELECT * FROM alunos LIMIT 5;
  ```
- **OFFSET:** Pula um número específico de registros antes de começar a retornar os resultados (útil para paginação).
  ```sql
  SELECT * FROM alunos ORDER BY nome ASC LIMIT 5 OFFSET 10;
  ```
- **Consultas Aninhadas (Subqueries):** Permite inserir uma consulta dentro de outra para realizar filtros ou cálculos.
  ```sql
  SELECT nome, idade FROM alunos
  WHERE idade > (SELECT AVG(idade) FROM alunos);
  ```
- **JOIN:** Combina registros de duas ou mais tabelas com base em uma coluna relacionada.

### Tipos de JOIN

- **INNER JOIN:** Retorna apenas os registros com correspondência em ambas as tabelas.
  ```sql
  SELECT a.nome, c.nome_curso
  FROM alunos a
  INNER JOIN cursos c ON a.curso_id = c.id;
  ```
- **LEFT JOIN (LEFT OUTER JOIN):** Retorna todos os registros da tabela à esquerda e os registros correspondentes da tabela à direita. Se não houver correspondência, os valores da tabela à direita serão nulos.
  ```sql
  SELECT a.nome, c.nome_curso
  FROM alunos a
  LEFT JOIN cursos c ON a.curso_id = c.id;
  ```
- **RIGHT JOIN (RIGHT OUTER JOIN):** Retorna todos os registros da tabela à direita e os registros correspondentes da tabela à esquerda.
  ```sql
  SELECT a.nome, c.nome_curso
  FROM alunos a
  RIGHT JOIN cursos c ON a.curso_id = c.id;
  ```
- **EXPLAIN:** Exibe o plano de execução da consulta, auxiliando na identificação de problemas de performance.
  ```sql
  EXPLAIN SELECT * FROM alunos WHERE idade >= 18;
  ```

# 2. DDL (Data Definition Language) – Definição da Estrutura do Banco

Os comandos DDL são utilizados para criar e modificar a estrutura do banco de dados, como tabelas, índices e outros objetos.

## CREATE

Cria uma nova tabela ou objeto no banco de dados.

**Exemplo:**
```sql
CREATE TABLE alunos (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nome VARCHAR(100) NOT NULL,
    idade INT,
    curso_id INT
);
```

## ALTER

Permite alterar a estrutura de uma tabela já existente.

- **ADD COLUMN:** Adiciona uma nova coluna à tabela.
  ```sql
  ALTER TABLE alunos ADD COLUMN email VARCHAR(100);
  ```
- **ADD INDEX:** Cria um índice para melhorar a performance das consultas.
  ```sql
  ALTER TABLE alunos ADD INDEX idx_nome (nome);
  ```

## DROP

Remove uma tabela ou outro objeto do banco de dados.

**Exemplo:**
```sql
DROP TABLE alunos;
```

# 3. DML (Data Manipulation Language) – Manipulação dos Dados

Os comandos DML são utilizados para inserir, atualizar e excluir registros nas tabelas.

## INSERT

Adiciona novos registros a uma tabela.

**Exemplo:**
```sql
INSERT INTO alunos (nome, idade, curso_id) VALUES ('João', 22, 1);
```

## UPDATE

Atualiza os dados de registros existentes.

**Exemplo:**
```sql
UPDATE alunos SET idade = 23 WHERE nome = 'João';
```

## DELETE

Remove registros de uma tabela.

**Exemplo:**
```sql
DELETE FROM alunos WHERE nome = 'João';
```

# 4. DCL (Data Control Language) – Controle de Acesso

Os comandos DCL são usados para gerenciar as permissões e o acesso aos dados do banco.

## GRANT

Concede permissões a um usuário ou grupo para executar ações específicas no banco de dados.

**Exemplo:**
```sql
GRANT SELECT, INSERT ON alunos TO 'usuario'@'localhost';
```

## REVOKE

Remove permissões que foram previamente concedidas.

**Exemplo:**
```sql
REVOKE INSERT ON alunos FROM 'usuario'@'localhost';
```

# 5. DTL (Data Transaction Language) – Gerenciamento de Transações

Os comandos DTL são essenciais para garantir a integridade e a consistência dos dados durante operações que envolvem múltiplos passos.

## BEGIN

Inicia uma transação, agrupando uma série de comandos SQL que serão executados como uma unidade.

**Exemplo:**
```sql
BEGIN;
UPDATE contas SET saldo = saldo - 100 WHERE id = 1;
UPDATE contas SET saldo = saldo + 100 WHERE id = 2;
```

## COMMIT

Confirma todas as operações realizadas dentro da transação, tornando as alterações permanentes no banco de dados.

**Exemplo:**
```sql
COMMIT;
```
Se o `COMMIT` for executado após os comandos acima, as alterações feitas nos saldos das contas serão gravadas permanentemente.

## ROLLBACK

Reverte todas as operações feitas na transação, retornando o banco de dados ao estado anterior ao início da transação.

**Exemplo:**
```sql
ROLLBACK;
```
Se o `ROLLBACK` for executado após os comandos de `UPDATE`, nenhuma modificação será aplicada às contas, garantindo que os dados permaneçam inalterados caso ocorra um erro durante a transação.

## Exemplo Completo

Abaixo está um exemplo completo de uso da linguagem de transação para garantir a transferência segura de valores entre contas bancárias.

```sql
BEGIN;

-- Subtrai 100 da conta de origem
UPDATE contas SET saldo = saldo - 100 WHERE id = 1;

-- Adiciona 100 à conta de destino
UPDATE contas SET saldo = saldo + 100 WHERE id = 2;

-- Se todas as operações forem bem-sucedidas, confirma a transação
COMMIT;

-- Caso ocorra um erro em qualquer operação, podemos desfazer as mudanças
-- ROLLBACK;
```

Esse mecanismo é essencial para evitar inconsistências e garantir que o banco de dados mantenha sua integridade em operações críticas.
